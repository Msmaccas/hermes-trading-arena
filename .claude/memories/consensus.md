# Cross-Session Consensus Tracker

## Purpose

This file tracks observations, patterns, and conclusions that persist across multiple arena competition runs. It prevents each session from starting from zero — enabling cumulative learning about persona behavior, market regimes, and stock universes.

## Structure

Each entry has: **Date | Stock/Theme | Finding | Persona(s) | Evidence Count**

## How To Use

1. **After each arena run**, add entries for any recurring patterns
2. **If the same finding appears 3+ times** across different sessions, promote it to a permanent observation
3. **If personas consistently agree** on a stock, flag it for the review queue
4. **If personas consistently disagree** on a stock, flag it as a high-conviction debate for deeper analysis
5. **Track persona drift** — if a persona's methodology seems to produce different results over time, note it here

## Categories

| Category | What To Note |
|----------|-------------|
| **Persona Bias** | Stocks/persona consistently over/underrates |
| **Market Regime** | Conditions where certain personas outperform |
| **Sector Performance** | Persona agreement/disagreement by sector |
| **Methodology Gaps** | Stocks that no persona's framework handles well |
| **False Signals** | Past setups that looked good but failed — shared data point |
