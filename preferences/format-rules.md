# Format Rules — Trading-Arena Fidelity Report Standards

## Report Structure

Every persona analysis must follow this exact structure:

### Header
```
Persona: <Name>
Methodology: <CAN SLIM / GARP / SEPA / Moat / Episodic Pivot / etc.>
Market: <US / HK / A-shares / JP / KR / IN / UK / BR / EU>
Ticker: <TICKER>
Date: <YYYY-MM-DD>
```

### Sections (Required)

#### 1. Business Overview (2-3 paragraphs)
- What does the company do? (plain English)
- Revenue breakdown by segment
- Geographic exposure
- Competitive position in 1 sentence

#### 2. Financial Health (Minimum 3 years)
- **Revenue**: YoY growth for last 3 fiscal years + TTM
- **EPS**: Diluted EPS trajectory (quarterly + annual)
- **Margins**: Gross, Operating, Net — trend analysis
- **Balance Sheet**: Cash vs. Debt, Current Ratio, Debt/Equity
- **Cash Flow**: Operating CF, Free Cash Flow, FCF conversion rate
- **ROE/ROIC**: Minimum 3-year track record
- **Share Count**: Dilution/buyback history

#### 3. Competitive Position
- Industry structure (Porter's 5 Forces lens)
- Market share data if available
- Moat assessment (Buffett's 4 types framework)
- Key competitors and relative positioning

#### 4. Risk Factors (Bullet Point — Minimum 5)
- Company-specific risks
- Industry risks
- Macro/geopolitical risks
- Regulatory risks
- Bear case specific to this persona's methodology

#### 5. Valuation
- Current P/E (trailing + forward)
- PEG ratio (Lynch) / Owner Earnings (Buffett) / CAN SLIM score (O'Neil)
- EV/EBITDA, P/S, P/B for cross-checking
- Comparison to sector median and historical range
- DCF or intrinsic value range (if applicable)

#### 6. Technical Setup (Only for technical/hybrid personas)
- Chart pattern identified (with specific dates)
- Current price relative to key MAs (10/20/50/150/200)
- Volume analysis (current vs 50-day average)
- Pivot point / buy zone
- Stop loss level
- Price targets (with methodology)

#### 7. Persona-Specific Analysis
- **O'Neil**: CAN SLIM score (C/A/N/S/L/I/M individually scored)
- **Buffett**: Four Gates assessment, Owner Earnings, Moat rating
- **Lynch**: Stock category, PEG ratio, 13-point checklist score
- **Minervini**: SEPA score, VCP contraction count, Trend Template check
- **Qullamaggie**: Setup match (Episodic Pivot / Breakout / Parabolic Short), Fib extensions
- **David Ryan**: Earnings acceleration trajectory, RS rating, first breakout check
- **Matt Caruso**: ATR-based position sizing, R-multiple framework, pyramid plan
- **Brian Shannon**: AVWAP levels, multiple timeframe alignment, ATR channels
- **Dan Zanger**: Chart pattern match, 10 Keys assessment, volume structure
- **Nick Schmidt**: Weekly chart structure, 10/30 SMA support, controlled base quality

#### 8. Bear Case (Required — Never Optional)
- Minimum 3-5 paragraphs
- Must contradict the bull thesis directly
- Must be as factually grounded as the bull case
- Include specific catalysts that could trigger the downside

#### 9. Verdict
- **Score/100**: Methodology-specific numerical score
- **Rating**: Strong Buy / Buy / Hold / Avoid / Short
- **Confidence**: High / Medium / Low
- **Position size** (as % of portfolio according to persona's rules)
- **Entry price**: Specific level
- **Stop loss**: Specific level
- **Price targets**: Specific levels with timeframes

## Language Standards

- Use **specific numbers** — no "high growth" — say "42% YoY revenue growth"
- Use **specific dates** — no "recently" — say "Q1 2026"
- Use **specific prices** — no "broke out" — say "broke out at $147.32 on 2026-06-01"
- Every quantitative statement must have a verifiable source
- Avoid superlatives unless they are objectively verifiable

## What To Never Do

- Never give financial advice ("you should buy/sell")
- Never guarantee future performance
- Never use "to the moon" / "moon shot" / "easy money" language
- Never use unverified rumors or "sources say"
- Never reference non-public information
- Never make price predictions beyond the persona's methodology framework
